FEATURES

一套把训练管到底的本机规则

周框架自己点

哪天练、练哪个部位由你决定。组数、次数、重量按你的器械条件、伤病记录和逐组历史算，排课不请求任何模型。

今日清单

每天生成一张按顺序往下做的清单。今天点几个部位就排几个，练哪天自己在那个页面上挪。

重量只往上推

动作记过一次之后，重量只按你自己的记录往上推，不再用估算值。做满次数才加。

109 个动作

按部位分区，每个动作有本机画的 SVG 示意、发力顺序、常见错误和同肌群替代。44 个动作预置示范视频链接。

饮食参考

按 Mifflin-St Jeor 估基础代谢再乘活动系数给一日热量，另有蛋白、碳水、脂肪、糖、钠五项区间和常见食物表。

体重腰围打卡

每天称一次、隔几周量一次。判断按最近两个 7 天平均相减，不按某一天说话。

PRIVACY

数据只存本机。

档案、周框架、训练和饮食记录默认留在这台设备的浏览器里，可以导出成一份 JSON 自己留着，也能导回来。登录是可选的；云端备份不点「传到云端」，就一个字节都不上来。
