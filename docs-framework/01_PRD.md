# 01 · 产品需求说明（PRD）
> 本文档是项目的需求契约。编码、接口、表结构、测试均以 `docs-framework/` 为准，禁止臆想字段与路径。

## 1. 背景与定位

「练」是一个移动端优先的训练计划 PWA：把「想练成什么样」翻译成周框架和当天可执行的训练清单。用户当天点几个部位，就排几个动作；训练时不计时、不掐点，只记录重量、次数和感受。

- 产品名：练 · 周框架与今日清单
- 形态：React SPA + PWA（可安装到主屏、支持离线打开已缓存页面）
- 数据策略：本机 localStorage 为主，云端只做整份备份；大模型 Key 只存本机
- 账号策略：登录后才能建档、训练记录与饮食记录
- 商业形态：账号密码 / 支付宝登录 + Pro 订阅

## 2. 核心术语

| 术语 | 含义 |
|---|---|
| 档案 profile | 性别、年龄、身高体重、训练年限、伤病、器械、可练天数、目标愿望 |
| 周框架 framework | 一次生成的多周训练安排，包含每天 focus、动作槽位与规则 |
| 今日清单 sheet | 某一天的训练表，由周框架或当天部位生成 |
| 动作槽位 slot | 清单中的一行，包含动作 ID、组数、次数、休息、替代动作 |
| 逐组记录 setLog | 某动作某组的重量、次数、RPE、是否力竭 |
| 其他运动 activity | 有氧、球类、举铁、走路等非清单训练 |
| 云端记录 | 用户整份业务数据快照，整份覆盖上传，不做字段合并 |
| VIP / Pro | 订阅状态，当前仅影响展示与到期时间，不拦截功能 |
| 体验账号 | `DEMO_LOGIN_ENABLED=true` 时创建的免密验证账号 |

## 3. 角色与权限

| 角色 | 说明 | 权限边界 |
|---|---|---|
| 匿名访客 | 未登录 | 仅欢迎页、账号页（登录/注册）、隐私政策、服务条款 |
| 普通用户 USER | 已登录 | 建档、训练、饮食、记录、云端备份、修改密码、查看自己的操作日志 |
| 管理员 ADMIN | `role = ADMIN` | 普通用户全部权限 + `/api/v1/admin/**`：账号管理、VIP、订单、全量操作日志 |

- 登录是使用业务功能的前置条件；未登录访问业务路由统一回到 `#/welcome`。
- 停用账号保留用户名，旧 JWT 立即失效，且不允许同名重新注册。
- 管理员不能停用自己，系统至少保留一个启用中的管理员。

## 4. 业务闭环

1. 首次使用：欢迎页 → 登录/注册 → 建档 → 生成周框架 → 回运动页
2. 日常训练：选部位 → 今日清单 → 训练中逐组记录 → 记录页查看
3. 饮食记录：饮食页选餐次与食物 → 记录营养 → 查看目标差值
4. 跨设备：数据与备份 → 上传云端 → 新设备登录 → 拉回云端
5. 订阅：账号页下单 → 支付宝收银台 → 异步通知发货 → 到期时间顺延
6. 管理：管理员搜索账号 → 停用/启用 → 手填天数开通 VIP → 订单退款 → 查操作日志

## 6. 页面与元素拆解

### 6.1 前台

**欢迎页 `#/welcome`**
- 品牌字「练」、主标题、副标题、三行价值点卡片。
- 未登录：主按钮「登录 / 注册后开始」→ 账号页；「支付宝登录 / 注册」按钮；提示「登录后才能建档、记录训练和查看饮食；记录默认只存在这台设备」。
- 已登录：主按钮「花两分钟建档」→ 建档页；次按钮「先随便练练」直接进运动页；底部「已登录 · 查看账号」。

**账号页 `#/settings/account`**
- 未登录：账号密码卡片（登录/注册两个 Tab）、账号、密码、确认密码、昵称、隐私政策勾选；未勾选时注册按钮置灰；快捷登录卡片仅在服务端开启时显示「体验用户」「体验管理员」；支付宝登录卡片；错误提示条。
- 已登录：已登录卡片（登录方式、账号、昵称、支付宝尾号、订阅、注册时间、最近登录）；修改密码卡片（仅本地密码账号，含原密码/新密码/确认密码，改密后旧令牌失效）；最近操作卡片；订阅卡片（价格、到期时间、升级/续费按钮，未开通收款时显示「收款还没开通」）；云端记录卡片（去备份、刷新、退出）；注销卡片（二次确认）。

**建档页 `#/setup`**
- 分步问卷：性别、年龄、身高、体重、体脂、训练年限、伤病部位、器械条件、每周可练星期、单次时长、目标愿望。
- 每步「上一步 / 下一步」；可跳过身体数据；完成后生成档案并进入周框架。

**运动页 `#/train`**
- 顶部 hero：本周训练进度与「开始训练」主按钮。
- 周框架卡片：周期、每周天数、今日 focus；点击进周框架页。
- 今日清单：动作行含组数×次数、替换、跳过；底部「完成训练」。
- 空态：未生成框架时引导「生成周框架」或「今天练哪里」。

**周框架页 `#/plan`**
- 4 周折叠列表，每天显示 focus、动作数、预计时长；可重新生成、回运动页。

**选部位页 `#/pick`**
- 部位 chips 多选（胸/背/肩/手臂/腿/臀/核心/全身/有氧）；时长预算；「生成今日清单」主按钮。

**训练中页 `#/session`**
- 每个动作一组行：重量输入、次数输入、RPE、力竭开关、完成勾选；支持跳过本组/本动作。
- 顶部显示动作名、目标组次与注意事项；底部「结束训练」，结束后写入 setLog 与 activityLog。

**动作页 `#/moves`**
- 部位折叠列表、搜索、收藏心形按钮、加入今日清单按钮；动作详情抽屉含要点、常见错误、伤病风险、替代动作。

**记录页 `#/log`**
- 日期切换与日历；逐组记录列表；其他运动记录表单（类型、时长、感受、备注）；体重/腰围打卡；删除按钮带二次确认。

**饮食页 `#/diet`**
- 目标卡片：TDEE、热量区间、蛋白质目标；四餐分区（早餐/午餐/晚餐/加餐）。
- 食物检索、份量输入、添加按钮；当日汇总与差值；体重趋势提示。

**设置页 `#/settings`**
- 入口卡片：我的档案、链接大模型、账号、数据与备份、离线与安装、安全边界；管理员额外显示「管理后台」。
- 子页：档案表单、模型配置（baseURL/apiKey/model、测试连通性，Key 只存本机）、数据与备份（导出/导入/云端上传/拉回/删除/清空）、离线说明、安全边界。

**法务页 `#/privacy`、`#/terms`**
- 隐私政策与服务条款全文；注册时必须勾选同意。

### 6.2 后台 `#/admin`

- 顶部 Tab：账号管理、订单管理、操作日志。
- 搜索框 + 搜索按钮；订单管理额外提供状态 pills（全部/待支付/已支付/已关闭/已退款）。
- 账号卡片：账号、角色标签、启用/停用标签、昵称、订阅与到期时间、注册时间；按钮「停用/启用」「开通 VIP」。
- 订单卡片：订单号、状态标签、账号、金额、天数、下单/支付/退款时间；待支付显示「关闭订单」，已支付显示「退款」。
- 日志卡片：动作、结果标签、操作人 → 对象、详情、时间、IP。
- 分页：上一页 / 第 N/M 页 / 下一页。

## 7. 业务规则

- 注册：账号 3-32 位字母数字下划线；密码 8-64 位；必须勾选隐私政策与服务条款；注册成功直接登录。
- 登录限流：同一 IP + 账号每分钟最多 5 次；Redis 不可用时退回内存计数。
- JWT：默认 2 小时；登出与改密后旧 `jti` 进入 Redis 黑名单。
- 云端同步：整份覆盖，请求体 ≤ 8 MB，每类记录 ≤ 20000 行。
- 订单状态机：`created → paid → refunded`，未支付可 `created → closed`。
- 退款：仅 `paid` 可退，调用支付宝全额退款，成功后扣回该单 VIP 天数；未配置支付宝时拒绝退款。
- VIP：从「当前到期时间」与「现在」中较晚者开始顺延，管理员可手填 1-3650 天。
- 管理操作与账号操作全部写入 `operation_log`，只追加不修改。

## 8. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首屏可交互 ≤ 2s（本地）；单接口 p95 ≤ 300ms（本地库）；云端同步 8MB 内可完成 |
| 安全 | 密码 BCrypt 强度 10；JWT 无状态 + Redis 黑名单；登录限流；管理接口强制 ADMIN；参数校验与统一错误码 |
| 隐私 | 业务数据默认只存本机；模型 Key 只存 localStorage；云端上传需用户手动触发 |
| 兼容 | iOS Safari、Android Chrome、桌面 Chrome/Edge 最新两个大版本；PWA 可安装 |
| 可用性 | Redis 故障时登录、限流降级可用；数据库故障返回 500 且不泄露堆栈 |
| 可维护 | 单文件 200-300 行以内；分层清晰；文档与 DDL/API 单一真源 |

## 9. 安全边界（产品硬约束）

- 不做医疗诊断，不替代医生或注册营养师
- 不安排极限重量、不鼓励带伤硬练
- 不建议低于女性 1600 kcal/天、男性 2000 kcal/天
- 不设计超过 24 小时的断食
- 不推荐补剂具体剂量、不涉及药物或运动营养处方
- 出现疼痛、麻木、关节刺痛时优先停止并建议就医

## 10. 非目标与已知缺口

- 不做训练计时/倒计时、社交、排行榜、教练入驻、食物拍照识别
- 无趋势统计页、无提醒通知、Pro 暂无实际权益
- 云端同步无冲突处理；支付宝登录与支付需真实凭据
- 已有 42 个单元测试 + 4 个 MySQL 集成测试；Docker 编排已提供，CI 待补
